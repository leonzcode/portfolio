Polar Graphing Calculator — Help

Polar Equations: r = 2 + 3sin(x), r = 4cos(2x)

Angle Lines: x = pi/4

Points: (3, pi/6) — format is (r, θ)

Sliders: Type r = a*sin(b*x) — unknown letters become sliders.

Constants: pi (π), e (Euler's number)

Functions: sin, cos, tan, sec, csc, cot, asin, acos, atan, sqrt, abs, log (base-10), ln

Implicit multiply: 2sin(x) = 2*sin(x), 3x = 3*x

Trace: Click the ▸ arrow on an expression to trace the curve with a θ slider.

Navigate: Drag to pan, scroll to zoom. Hover curves for coordinates.

Tip: Type x for the angle variable — it displays as θ. Negative r values plot correctly.
